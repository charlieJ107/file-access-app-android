# 媒体连续预览

从文件列表或网格点开媒体后，左滑查看下一项，右滑查看上一项。也可使用“上一项”“下一项”按钮；首尾不循环。文件名、序号和下载操作对应当前停稳的媒体。

## 浏览范围

- 图片与视频在同一队列中浏览；音频在音频队列中浏览。文本、PDF 和其他文件仍按单文件预览，PDF 的内部翻页独立保留。
- 队列来自点击时当前目录已加载、搜索筛选及排序后的列表。目录和其他文件不会混入媒体队列，也不递归进入子目录。
- 本次浏览的队列固定，后台目录加载不会重新排列正在查看的项目。目录尚未完整加载时显示提示；返回目录加载完成后重新打开，可浏览完整队列。
- 加载失败、文件删除、格式不支持或文件过大时显示错误，可以重试、下载或继续切换，不自动跳过项目。
- 返回一次退出预览，保留目录搜索、排序、列表/网格模式与滚动位置。

## 状态与资源

`PreviewViewModel` 持有当前会话的媒体列表。导航及保存状态只包含会话标识、目录、当前文件、筛选排序条件和连接配置版本，不序列化整份目录。

旋转屏幕后保留当前会话；进程重建后按目录和筛选条件重新生成列表，并按文件引用定位。远端目录可能已发生变化，因此恢复后的队列不保证与进程结束前完全一致。恢复失败时显示错误并允许重试，不静默跳到别的文件。连接配置版本不符时阻止旧会话读取新的远端目标。

分页采用 Compose `HorizontalPager`。只有当前停稳页加载原始媒体，邻页显示占位，不提前下载原图或准备音视频播放器。快速翻页会取消旧页面请求；加载状态按文件隔离，旧请求不会覆盖新页面。阻塞式图片读取通过可中断协程运行，取消后关闭流、释放缓存锁并清理临时文件；底层协议的超时和中断响应仍影响实际等待时间。

视频画面区域可左右滑动，播放按钮与进度条使用独立 Compose 控件。开始翻页时暂停；离开页面、进入后台或退出预览后释放播放器。重新查看同一版本的媒体时恢复本次会话中的进度，保持暂停。系统边缘返回手势保留。图片缩放不属于此次功能。

预览仍保留单个图片/PDF 128 MiB、缓存预算 256 MiB、24 小时淘汰及远端版本核对。媒体类型识别复用浏览页规则；是否可解码取决于文件内容和设备。此功能不新增依赖、不改变发布或签名流程。

## 验证

围绕队列顺序、同名文件身份、音频分组、部分目录、状态恢复、分页首尾、连续滑动、下载目标、错误重试、播放器释放与取消下载清理增加自动化测试。设备测试使用 Android 16 模拟器与合成媒体/隔离存储提供方，不连接真实 NAS。

2026-09-16 本地验证结果：

| 检查 | 结果 |
| --- | --- |
| Debug APK / AndroidTest APK | 构建通过，开发证书签名 |
| App JVM 测试 | 35/35 通过，其中新增队列与进度测试 8 项 |
| Android 16 API 36 设备测试 | 31/31 通过，0 失败、0 跳过 |
| Android Lint Debug | 0 错误、13 警告（依赖版本、现有未使用资源、空间 API 与 KTX 建议），没有新增 baseline |
| 应用启动 | MainActivity 冷启动成功，模拟器 crash buffer 无记录 |

设备用例包括预览缓存/取消 5 项、会话/恢复 6 项、分页界面 5 项、播放器 5 项、浏览界面 6 项及既有基础界面 4 项。播放器生命周期/手势测试使用包装的本地 ExoPlayer，图片和加载测试使用合成媒体提供方；此轮没有运行真实 SMB 服务或真实 NAS 的网络回归，不能将模拟器结果视为真实网络或所有媒体编码均已验证。

构建命令：

```powershell
.\scripts\build.ps1 :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug --console=plain
```

设备测试指定 `emulator-5556`。缓存测试通过 Gradle `connectedDebugAndroidTest` 运行；其余 26 项通过 `adb -s emulator-5556 shell am instrument -w -r -e class <逗号分隔的测试类> space.zhuoling.fileaccess.test/androidx.test.runner.AndroidJUnitRunner` 运行。此次 Gradle 多类过滤实际只执行了第一个测试类，因此以 XML 测试数量和 AndroidJUnitRunner 的 `OK (26 tests)` 分别核对结果，没有将未执行的类计为通过。
