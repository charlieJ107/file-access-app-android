# FileAccess v0.2.0

新增媒体连续预览：在查看界面左滑下一项、右滑上一项。图片和视频按当前目录的搜索及排序顺序混合浏览，音频在独立队列中浏览；提供位置计数、上一项/下一项按钮及当前文件下载。

- 首尾不循环；加载失败时可以重试或继续切换。
- 返回目录保留浏览位置，旋转和进程重建按文件身份恢复当前项。
- 视频切走或应用进入后台后释放播放器；回看恢复本次会话的播放进度并保持暂停。
- 快速切换取消旧请求，损坏图片可强制重新读取，保留缓存预算、文件大小及远端版本校验。
- 修复按文件大小排序时遇到未知大小可能发生的类型错误。

版本由 `version.properties` 定义：`versionName=0.2.0`、`versionCode=2`。正式 APK 通过 `master → release` PR 与 GitHub Actions 构建、签名和发布，文件名为 `fileaccess-2.apk`，附 `SHA256SUMS`。

功能开发阶段已通过 35 项 JVM 测试、31 项 Android 16 模拟器测试和 Debug Lint；详见[媒体连续预览验证记录](../media-preview.md)。发布构建及签名连续性以本次发布工作流结果为准。相邻页暂不预取原始媒体；真实手机、NAS 弱网和 TalkBack 的完整人工验收尚未完成。
