# 01 产品需求

## 产品定位

一个由自己掌控的远端文件客户端：方便访问家庭 NAS 和自建网盘，并能可信地备份手机照片、视频。主要价值是清楚的数据流向、可靠的文件操作和可恢复的后台传输。

产品原则：远端优先；操作结果可解释；大文件以流处理；离线和网络波动是正常状态；任何自动操作都不能悄悄扩大权限、覆盖不同内容或传播删除。

## 使用场景

| ID | 场景 | 成功结果 |
| --- | --- | --- |
| U01 | 在家打开 NAS 的电影/相册目录 | 看到文件，图片可放大，视频在支持时可拖动播放 |
| U02 | 外出通过自建网盘或已有 VPN 取文件 | 能判断服务器不可达、权限问题和本机网络问题 |
| U03 | 拍摄后回到符合规则的网络 | 照片进入自动备份队列；已备份内容可定位到远端 |
| U04 | 手动上传大型视频后切到其他应用 | 显示系统传输通知；受系统中断后可恢复或明确重传 |
| U05 | 整理远端目录、批量移动和重命名 | 操作前知道目标和影响，部分失败可定位到单文件 |
| U06 | 服务器或手机故障后找回资料 | 下载副本可验证；加密空间能在新设备恢复 |
| U07 | 需要脱网查看一份文件 | 标记为离线，能区分缓存版本和最新远端版本 |

## 功能清单与优先级

P0 是 NAS 首版必须具备的能力；P1 是随后增强及 S3 / 私有网盘接入；P2 为后续规划。用户已确认 NAS 优先，现有私有 API 与加密资料后续再提供。阶段验收见 07。

| ID | 功能 | 优先级 | 范围与完成条件 |
| --- | --- | --- | --- |
| F01 | 多连接管理 | P0 / P1 | 首版 SMB / WebDAV 的编辑、测试、删除、账号隔离；后续 S3 / 私有 API 通过接口接入 |
| F02 | 远端浏览 | P0 | 目录层级、面包屑、列表/网格、排序、分页或流式列表、刷新 |
| F03 | 文件基础操作 | P0 | 新建目录、重命名、删除、上传、下载、多选；按服务能力降级 |
| F04 | 复制与移动 | P0 | 同连接操作；非原子操作显示任务和部分结果；不支持时明确说明 |
| F05 | 预览 | P0 | 图片、常用音视频、有限大小文本、PDF；未知格式安全交给外部应用 |
| F06 | 传输中心 | P0 | 队列、字节进度、暂停、继续、取消、重试、等待原因、历史 |
| F07 | 自动照片/视频备份 | P0 | 显式选来源、目标和条件；增量发现；本机删除不影响远端 |
| F08 | 冲突保护 | P0 | 默认保留双方或跳过；不能仅按时间戳自动覆盖 |
| F09 | 搜索/收藏/最近 | P0 | 当前目录名称搜索、收藏目录、最近访问；搜索范围明确 |
| F10 | 权限与信任 | P0 | 按需申请媒体、目录、通知、局域网权限；安全保存凭据 |
| F11 | 离线副本 | P1 | 显式下载、版本提示、限额和移除；普通缓存不等于离线保证 |
| F12 | 跨连接复制 | P1 | 默认经手机中转；展示流量、空间和加密边界 |
| F13 | 回收站和历史版本 | P1 | 仅在远端真正支持时展示恢复操作 |
| F14 | 双向同步 | P1 | 三方状态比较、冲突、删除墓碑、预演、暂停规则 |
| F15 | 全局搜索 | P1 | 服务端搜索或用户授权的本地索引；不默认扫描整个 NAS |
| F16 | 私有网盘 E2EE | P1 | 等待已有方案资料；加密能力必须通过恢复与兼容性验收后启用 |
| F17 | Android 系统文件入口 | P2 | DocumentsProvider，其他应用通过系统选择器访问远端 |
| F18 | 扩展预览 | P2 | 压缩包、RAW、字幕、办公室文档；评估解析器成本后纳入 |

首版不包含广告、付费解锁、强制开发者云账号、Root、全盘清理、存储测速仪表盘、自建 VPN、在线协作文档或自己开发 Office 渲染引擎。

## 备份与同步的产品语义

| 模式 | 新增 | 修改 | 本机删除 | 远端删除 |
| --- | --- | --- | --- | --- |
| 备份（默认） | 上传 | 创建新版本/另存副本 | 保留远端 | 标记副本缺失，可按规则重新备份 |
| 单向更新（P1） | 上传 | 条件替换或冲突 | 默认保留远端 | 按规则修复；不删除本机 |
| 镜像（P2） | 对齐源端 | 对齐源端 | 可能删目标；必须独立启用、先预演 | 以指定源为准 |
| 双向同步（P1） | 两端传播 | 三方比较和冲突 | 只有已知基线与明确删除事件才候选传播 | 同左；读取失败不能当删除 |

“自动”表示系统条件允许时执行，不承诺拍摄完成后数秒内到达 NAS，也不承诺特定时刻执行。页面同时展示“上次检查”和“上次成功备份”；没有新文件与尚未检查是不同状态。

## 备份规则

每条规则包含：名称、本机来源、媒体类型、历史文件起点、远端连接与目录、命名规则、网络条件、电源条件、加密空间、冲突策略和是否启用。

建议默认：照片和视频；用户选择是否包括已有媒体；目录 `相机备份/{设备名}/{年}/{月}`；保留原文件名，同名不同内容增加日期与短标识；仅 Wi-Fi 且非计费网络；低电量暂停；“仅充电”供用户选择。UTC 保存时间，界面按本地时区显示，归档日期优先使用可靠拍摄时间，缺失时回退媒体时间并保持结果稳定。

首次开启前展示一次扫描预估：可访问文件数量、已知总量、无法统计项、目标目录和条件。允许先备份少量样本。媒体库只获部分授权时显示“仅能备份已授权项目”，不能显示“全部照片已保护”。

自动备份永远不执行“上传成功后删除本机”。未来若增加释放空间功能，必须独立入口、展示待删除项，并验证远端可读取。

## 关键状态与可解释性

连接：未配置 / 检查中 / 可访问 / 离线 / 需要认证 / 需要局域网权限 / 证书待处理。连接状态是最近一次结果，不是假定长久在线。

文件：远端已知 / 元数据过期 / 传输中 / 已离线 / 离线版本过期 / 不支持预览 / 已加密且锁定。

规则：尚未扫描 / 扫描中 / 待上传 / 上传中 / 等待网络 / 等待电源 / 等待解锁 / 需要授权 / 有冲突 / 用户暂停 / 本轮完成。

错误必须附可执行的下一步，例如“NAS 暂时不可达；已上传部分已保存”“目录授权失效；重新选择来源”。技术错误码留在详情中，敏感路径和凭据默认隐藏。

## 非功能目标

以下为验证目标，不是已实现性能：

| 项目 | 目标与测量条件 |
| --- | --- |
| 数据安全 | 断网/进程退出/响应丢失不产生未报告的覆盖、源文件删除或成功误报 |
| 大文件 | 20 GiB 测试视频传输不按文件大小分配内存；超大尺寸使用 64 位计数 |
| 大目录 | 10 万条元数据可持久化浏览；局部分页；不阻塞主线程 |
| UI 响应 | 基准真机的本地交互通常在 100 ms 内有反馈；外部请求立即给加载状态 |
| 缓存打开 | 中端测试机已缓存目录首屏 p95 ≤ 300 ms；联网完整列出时间单独记录 |
| 资源 | 默认至多 2 个文件同时传输，每连接 1 个，预览优先；通过测量再调参 |
| 隐私 | 无默认遥测；日志不含密码、令牌、签名 URL、加密明文或恢复材料 |
| 无障碍 | TalkBack、200% 字体、48 dp 点击目标、横竖屏与深色模式可用 |
| 可维护性 | 新增协议不修改同步判定算法；协议契约和持久化迁移有自动验证 |

## v1.0 完成定义

在明确支持的测试 NAS 上，SMB / WebDAV 均完成连接、浏览、读写和能力允许的管理操作，并能完成照片/视频备份及中断恢复。不能实现的能力在连接详情和操作入口说明。首版仅显示已实现的连接类型。

用户可回答：文件去了哪里、是否上传完成、如何恢复、任务为何暂停、凭据如何保护。后续加入私有网盘与 E2EE 时，还必须证明已有加密格式互通、换机恢复和锁定行为正确；不将等待 API 资料作为 NAS 首版的阻塞项。
